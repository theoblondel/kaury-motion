The API in one screen

Everything the studio does, you can write by hand. Import from the module or use the KauryMotion global from the script build.

animate

CSS, transforms, SVG attributes, CSS variables or plain objects. Colours and units blend.

animate('.card', {
  y: [60, 0],
  opacity: [0, 1],
  backgroundColor: '#F56E2E',
}, { delay: stagger(80), ease: 'kaury' })

spring

Real damped springs. Duration comes from the physics.

animate('.pill', { scale: [0.6, 1] }, {
  ease: spring({ stiffness: 220, damping: 12 }),
})

timeline

Sequence anything. Positions like '-=200' or '<' overlap steps.

timeline({ defaults: { ease: 'kaury' } })
  .add('.logo', { scale: [0, 1] })
  .add('.title', { y: ['110%', '0%'] }, {}, '-=500')
  .add('.cta', { opacity: [0, 1] }, {}, '<')

stagger

From first, last, center, edges or random. Works in 2D grids.

animate('.dot', { scale: [0, 1] }, {
  delay: stagger(40, { grid: [12, 8], from: 'center' }),
})

Text

Split into chars, words or lines, with an accessible label kept.

reveal('h1', { effect: 'rise', by: 'chars' })
scramble('.code', { text: 'KAURY' })
counter('.stat', { to: 12500, suffix: '+' })

Pointer, scroll, depth

Ongoing effects return a function that stops them.

magnetic('.btn', { strength: 0.4 })
tilt('.card', { max: 14, glare: true })
extrude('.logo', { depth: 40 })
scrub(timeline, { trigger: '.section' })

No JavaScript at all

Add the script with data-auto and write attributes. Effects combine with spaces.

<script src="kaury-motion.min.js" data-auto></script>

<h1 data-km="rise" data-km-by="chars">Give brands character</h1>
<div data-km="marquee" data-km-speed="120" data-km-scroll-boost="1">…</div>
<div data-km="extrude tilt float" data-km-depth="40"><svg>…</svg></div>
